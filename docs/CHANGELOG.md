# Changelog

All notable changes to the **Riftwalker: Paradox Protocol** project will be documented in this file.

## [0.1.0] - 2026-08-29
### Added
- Comprehensive architecture and project specification (`Riftwalker_Paradox_Protocol_Project_Spec_v2.md`).
- Project repository structure with modular splits for M1 (Player/Camera), M2 (Enemies/Combat), M3 (World/Teleport), M4 (Rendering/Integration), and `shared/`.
- Full `.gitignore` covering Python, PyOpenGL, GPU captures, OS files, and IDE configs.
- Core shared mathematical utilities (`math3d.py`), time management (`game_time.py`), input handling (`input_manager.py`), and constants (`constants.py`).
- Initial OpenGL graphics sandbox entry point (`src/main.py`).
- Test suite structure in `tests/`.
